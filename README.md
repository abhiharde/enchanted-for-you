# EnchantedForYou

A free, static romantic music site. No build step or server is required.

## Make it yours

1. Open `script.js` and replace `PASTE_YOUR_PUBLIC_YOUTUBE_PLAYLIST_ID_HERE` with the value after `list=` in your public playlist URL.
2. The background illustration and love note are already included. Edit the note any time in `script.js`.
3. Upload these files to a free static host such as GitHub Pages, Netlify, or Vercel.

YouTube requires playback to start from a user action in most browsers, so she will need to press Play once. The embedded player is visually hidden; it plays audio only.
